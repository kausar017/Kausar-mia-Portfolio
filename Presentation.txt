I Creation Responsive Navbar in Next.js

I built a responsive Navbar using Next.js, Tailwind CSS, and ShadCN UI. It includes a logo, navigation links (Home, Courses, About, Dashbord), and a sign-up button. The navigation is handled using Next.js's Link component, and styling is done with Tailwind CSS for a modern look.

One challenge I faced was with Lucide-React icons, but I resolved it by properly importing the Link component. This project helped me understand Next.js routing, component structuring, and responsive UI design. I plan to deploy it on Vercel for a live preview.
